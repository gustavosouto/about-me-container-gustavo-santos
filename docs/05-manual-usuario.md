# Manual do Usuário

**Projeto:** About Me — Git Lab
**Item de configuração:** MAN-001
**Versão:** 1.0 · 31/08/2026

---

## 1. O que é a aplicação

Um site simples com duas páginas: uma página inicial e uma página "About Me" com o perfil acadêmico do responsável.

## 2. Como acessar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador (Chrome, Firefox, Edge).
3. Clique em **About Me** no menu para ver o perfil.

## 3. Como personalizar seu perfil

1. Abra o arquivo `about.html` em um editor de texto.
2. Substitua:
   - `Nome não informado` pelo seu nome completo;
   - `Não informado` pelo seu nível acadêmico (Graduação ou Pós-graduação);
   - `Não informada` pela sua área de interesse (Graduação) ou área de pesquisa (Pós-graduação).
3. Salve o arquivo e atualize a página no navegador para conferir.

## 4. Requisitos

Nenhum. A aplicação não depende de instalação de programas, bibliotecas ou banco de dados — basta um navegador.
